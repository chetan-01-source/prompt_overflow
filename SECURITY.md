# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use [GitHub private vulnerability reporting](../../security/advisories/new) on this repository. You'll get a response as soon as possible, typically within a few days.

## Scope

- The Next.js app (auth flows, server actions, API routes including `/api/mcp`)
- Supabase RLS policies in `supabase/migrations/`

Thanks for helping keep Prompt Overflow safe.
